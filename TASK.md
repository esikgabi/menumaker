# MenuMaker

ManuMaker is an application which helps a family to organise the next week menu. It tries to answer the tipical question "What should I cook?".

# Functional Criterias
 - Define meals
 - Tagging meals (child favourite, absolute favourte, parent favourite, healthy, fast to make)
 - Store the cooked meals
 - Plan the next week menu based on the cooking history and required tags

# Technical Requirements
 - It should be a web applicaiton which can be fit for mobile usage also (no native app version is needed, just from browser)
 - A simple database is needed where we can store the data
 - Authentication should handle via Google Authentication (password storing is prohibited)
 - App should support multiple language English and Hungarian at the beginning

# Running architecture
 - The application will run a docker container in a Rabsberry PI 5 model with 16GB RAM via openmediavault
